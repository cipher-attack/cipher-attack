### [~] whoami

I'm a developer and security researcher based in Ethiopia.

I don't use a traditional desktop setup. Almost all of my coding, testing, and security research happens directly on my Android phone. By rooting my daily driver and heavily relying on Termux, native Linux environments, and shell scripts, I've turned my mobile device into a complete workspace.

Working this way started out of necessity, but it pushed me to understand how the OS works under the hood at the kernel level.

### [+] current_focus

I'm currently focused on low-level Android hardware manipulation and building tools for physical security assessments. Instead of high-level app development, I spend my time interacting directly with the Linux kernel (ConfigFS, SysFS) and writing JNI/C++ bridges.

*   **Stack:** `C++` `Kotlin` `Python` `Bash`
*   **Interest:** Hardware Emulation, Kernel Modifications, Red Teaming
